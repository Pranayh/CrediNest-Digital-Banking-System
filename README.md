# EazyBank Web Application

EazyBank is a **banking web application** designed to simulate core banking operations such as account management, transactions, and secure user authentication. The project demonstrates how modern banking systems manage customer data and financial transactions using a scalable backend architecture.

The application allows users to register, log in, view account details, check transaction history, and perform basic banking operations through RESTful services. The system follows a **layered architecture** where the frontend interacts with backend services via REST APIs.

To ensure consistent deployment across environments, the application is **containerized using Docker**, enabling easy setup and portability for development and deployment.

## Key Features

* User registration and authentication
* Account management and dashboard
* View transaction history
* Fund transfer and basic banking operations
* RESTful API-based communication
* Containerized application using Docker

## Tech Stack

* **Backend:** Java, Spring Boot
* **Database:** MySQL
* **API Architecture:** REST APIs
* **Containerization:** Docker
* **Build Tool:** Maven
* **Version Control:** Git & GitHub

## Purpose

The purpose of this project is to demonstrate how a **modern banking application can be built using Spring Boot and REST APIs**, along with containerization using Docker to ensure consistent and scalable deployments.
